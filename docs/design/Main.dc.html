docs/plans/2026-10-11-t2-map-records.md 4 steps 2 files to change Planned in 8s · $0.42

Goal

Turn each parsed manifest entry into a row the writer accepts. T1 gave us parseManifest(), which returns ManifestEntry[], but nothing converts those entries into Row objects yet, so the importer stops right after parsing.

Approach

Add a pure function mapRecord(entry) in src/importer/map.ts. It copies the known fields, normalises createdAt to an ISO string, and drops unknown fields instead of passing them through. RowWriter.write() throws on keys it does not recognise, so one stray field would otherwise fail the whole batch.

export function mapRecord(entry: ManifestEntry, warn = noop): Row {
  const { id, name, createdAt, tags = [], ...rest } = entry;
  for (const key of Object.keys(rest)) warn(`ignored field: ${key}`);
  return { id, name, createdAt: toIso(createdAt), tags };
}

Dropped fields are counted, not lost silently. They go through the existing onWarning hook, so the import summary can say “3 fields ignored”.

Steps

  1. Write a failing test in map.test.ts for a record carrying an unknown field, legacyRef. It should be absent from the row, with exactly one warning emitted.
  2. Run npm test and confirm it fails for the right reason: mapRecord does not exist yet.
  3. Implement mapRecord and call it from importer.ts straight after parseManifest.
  4. Run the full suite, then commit as importer: map records to rows (T2).

Out of scope

The v1.2 runtime shim, which is T3. No field renames either: the current manifest version does not need any.

Risk

Older manifests send createdAt in two formats, ISO strings and epoch seconds. toIso already handles both, and the new test includes an epoch-seconds case so a regression shows up here first.
