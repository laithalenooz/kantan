簡単 kantan means “simple” in Japanese

Start with a repository.

kantan works through the tasks in a markdown file in your repo, one at a time. It writes a plan, waits for your OK, then implements it and runs your tests until the exit code says they pass.

  1. 1 Add a repository and choose the Claude account it runs under: personal or work.
  2. 2 Point at a task file such as docs/features/importer.md
  3. 3 Start a task. kantan plans it, then stops and waits for you.
