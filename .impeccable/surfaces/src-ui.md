Scope: the kantan operator surface. Visitor mode: Operate.

Audience: the owner, fluent in Claude Code, working across several real repos. Secondary: a
competent stranger who has never seen kantan. Task: take one task through plan, approval,
implementation and tests. Two scenes switched by the gate: close reading of a plan, then glancing
back after twenty minutes to see whether anything needs them.

## Direction contract

THESIS: kantan is a document of record, not a console. It refuses the dark operator terminal with
one neon accent, which is both this category's default arrangement and a documented
AI-interface cluster.

OWN-WORLD: the plaintext technical standard. Cool paper ground #F4F4F1, ink #17191C, hairline
rules #C9C9C3, numbered clauses, fixed measure, errata appended rather than edited. Public Sans
for prose and labels, Commit Mono for every machine value. One type size on the working surface;
rank carried by weight, case, reversal and rule, never by size. Colour follows the ISO safety
convention and is purely semantic: blue is mandatory action, green a safe condition, red danger,
yellow warning. A running phase has no colour, because it is merely happening. Colour commits at
region scale, never as accents scattered on grey.

STORY: the visitor reads a plan closely and decides once, then trusts the record. They believe
kantan because they can check it: every command, diff and exit code is in the document. They
approve, look away, and come back to an answer rather than a transcript.

FIRST VIEWPORT: ink on paper at density 8. Left, a numbered clause tree of projects, features and
tasks, each row carrying identical fields in identical positions. Centre, the run as an appended
record under a hairline rule. Right, phase, cost and window. No chrome, no cards, no shadows. When
a run needs the human, one region becomes a full-bleed blue plate with reversed type and the
primary action sits inside it; when nothing needs them there is no colour on screen at all.

FORM: the technical standard, published. Position 3 of seven on the ordered grounded list. Seed
key 0a22d5e1.

Raises, each from the challenger it beat: one type size only, rank by weight and case and rule
[rw-timetable-slide-rack]; the layout grid visible and toggleable as real state
[crouwel-grid-specimen]; colour committed at region scale [aww2-zoo-gardens-guide-map]; where
scale is used it is extreme, monumental against tiny mono [variable-font-specimen]; identical
fields in identical positions per row [pop-culture-shelf-character-goods-catalog]; honest
rendering, integer scaling, nothing softened [emigre-bitmap-specimen].

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
